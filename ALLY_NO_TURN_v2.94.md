# ALLY NO TURN — v2.94

Scene Allies can be marked **NO TURN** by the GM. This is a Scene-presence flag, not removal.

- Remains visible in Scene.
- Resources, Status, token link/spawn and targeting remain active.
- Excluded from Initiative Strip and all combat turn sequencing.
- `JOIN TURN` restores normal initiative participation.
- State is stored with the Scene monster record and persists with Scene metadata.
