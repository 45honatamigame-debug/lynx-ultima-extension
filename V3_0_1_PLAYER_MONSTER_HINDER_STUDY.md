# V3.0.1 — Player Monster HINDER / STUDY

Built directly from the supplied V3.0 archive.

- Player selects a linked Monster while no Token HUD is open: opens HINDER / STUDY only.
- Player cannot access Monster Actions, resources, setup, or Special Rules from this HUD.
- HINDER toggles the six standard statuses and respects Monster status immunity.
- STUDY rolls the Player character INS + INS + MOD and emits the existing Study roll payload so the GM background worker can auto-apply the unlocked tier.
- GM Monster click remains the full Monster Action HUD.
- Actor PIN behavior is unchanged for target selection.
