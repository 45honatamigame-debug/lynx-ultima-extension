# v2.120 · Travel Link Mode context toggle

- LINK MODE is opened/closed from right-clicking an empty area of the Node Board.
- The board context menu shows the current LINK MODE state.
- Turning LINK MODE off clears the selected Node A anchor.
- Turning LINK MODE on automatically leaves GM Player Rules mode to avoid conflicting interactions.
- Turning GM Player Rules on automatically closes LINK MODE.
- The old zoom-toolbar LINK MODE button was removed so there is one authoritative toggle path.
- Node Editor can set the selected node as A only while LINK MODE is already on.
- Escape remains a safety exit and now works even when an editor field has focus.
