# v2.142 — Node DETAIL is GM-only

- Player Node hover preview still shows the Node preview image, Node name, and map name when the Node is eligible for preview.
- Node `DETAIL` is no longer rendered into the Player preview popup at all.
- GM hover preview continues to show Node `DETAIL`, including for HIDDEN Nodes.
- GM Node Editor keeps the editable `DETAIL` field.
- Reveal / Discover state, preview eligibility, Unlock Rules, Explored Node Counter, and embedded Node Token Templates are unchanged.
