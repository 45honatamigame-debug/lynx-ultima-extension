# v2.115 — Travel UI usability

- Node cards compact only at extreme overview zoom, preventing full-size cards from piling on top of each other at 5–20%.
- GM editor sidebar can be collapsed and reopened with ▶ / ◀; the choice is remembered locally.
- GM WALK can toggle between ADMIN MODE and PLAYER RULES ON. Player-rule mode enables one-edge click movement, obeys locked Nodes, and uses the GM character's assigned A/B group when available. Hold Shift while dragging a reachable node to edit it.
