# v3.0.42 — Player Token Quick Menu Setting

- Player-token click quick menu is now OFF by default.
- Added Settings > PLAYER TOKEN QUICK MENU local toggle.
- When disabled, selecting/clicking linked Player tokens no longer auto-opens the Token Action HUD.
- Monster-token clicks remain unchanged for Player Study/Hinder and GM monster control.
- Turning the Player toggle OFF immediately closes a currently open Player Token HUD without closing Monster HUDs.
- Preference is stored locally per browser/device.
