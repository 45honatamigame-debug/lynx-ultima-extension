# v3.0.16 — Companion HUD on-canvas flow

- Enlarged labeled Companion HUD buttons.
- New orderly default layout: four shortcuts down each side and Travel at bottom center.
- Companion USE/ROLL no longer opens the main Owlbear action window.
- A dedicated centered Owlbear popover loads the same `app.js` in Companion Flow mode.
- Cost payment, roll results, Study, damage, Trait Invoke and Bond Invoke therefore use the exact main implementation.
- Closing the overlay closes the Companion Flow popover.
- Existing drag persistence and reset-position control remain unchanged.
