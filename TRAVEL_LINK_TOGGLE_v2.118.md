# Travel Link Toggle v2.118

- LINK MODE is now an explicit ON/OFF toggle.
- While ON, click Node A then Node B.
- If A and B are not connected, the undirected edge is created.
- If A and B are already connected, the edge is removed.
- LINK MODE remains ON after each pair for continuous graph editing.
- Clicking the same Node twice clears the current A anchor.
- ESC turns LINK MODE OFF.
