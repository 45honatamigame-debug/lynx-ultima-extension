# Travel explicit node creation · v2.113

- Removed double-click/implicit node creation from the Node Plan.
- Left click is reserved for selecting/dragging nodes and movement.
- GM can right-click an empty area of the Node Plan and choose **CREATE NODE HERE**.
- The new node is created at the exact right-click world position, respecting pan and zoom.
- The existing + NODE button remains available as an explicit alternative.
