# V3.0.66 — Collapsible Companion Travel Sessions

- GM Canvas Travel now has a `SESSIONS` toggle in its header.
- The current-session and `NEW SESSION` cards are collapsed by default in the shortcut.
- Expanding still exposes all session management controls.
- The preference is stored locally and does not change the main-window Travel layout.
- The reclaimed height keeps Node context menus inside the visible Travel overlay.
- Context menus also clamp themselves to every edge and gain an internal scrollbar only when necessary.
