# TRAVEL EXPLORER ICONS — v2.111

Node cards display who is currently exploring each location.

- Player Character Sheet portrait: cyan marker, `P` badge.
- Scene Ally portrait: green marker, `ALLY` badge.
- Split mode keeps the A/B group badge on every portrait.
- Existing manual `I'M HERE` player markers remain authoritative.
- Players without a manual marker automatically appear at their travel group's current Node.
- Allies follow MAIN before split and Group A by default after split.
