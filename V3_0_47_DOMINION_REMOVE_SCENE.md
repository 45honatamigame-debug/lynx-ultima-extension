# v3.0.47 — Dominion Remove from Scene

- Moved `REMOVE FROM SCENE` to the Companion shortcut: `DOMINION > MONSTER SHEET`.
- The button acts on the Monster selected in the Scene strip, including defeated Monsters.
- Confirmation is required before removal.
- Removal clears the Scene instance, linked Owlbear token, and related Guard/Cover connections.
- The Monster Template remains available in Dominion for future spawning.
- Removed the visible Remove shortcut from the clicked Monster Token HUD.
