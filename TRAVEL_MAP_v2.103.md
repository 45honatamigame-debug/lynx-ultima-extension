# TRAVEL MAP v2.103

TRAVEL is room-shared and stored in Scene metadata.

GM workflow:
1. Put maps in Owlbear Background (MAP layer).
2. Open TRAVEL and create a Session.
3. Create a Travel Frame or select a rectangular Shape and use it as the frame.
4. Link each Map Tab to a Background/MAP image.
5. Double-click the node board to create Nodes, drag them, and link LEFT/RIGHT/FORWARD/BACK.
6. Right-click a Node to lock/unlock, reveal/hide, set current, duplicate, or delete.

Player workflow:
- Only discovered Map Tabs and Nodes are rendered.
- Unknown destinations display ???? until entered/revealed.
- Locked destinations cannot be entered.
- Moving updates shared Scene metadata; the GM background extension switches the actual Owlbear Background map and fits it into the frame.
