# V3.0.57 — Ten-color Cut-in

- Every Player Action can enable Skill Cut-in, including ROLL, NO ROLL, Guard, and Cover Ally.
- Every Arcana entry can independently enable Skill Cut-in.
- Each entry can select Violet, Cyan, Blue, Green, Lime, Gold, Orange, Red, Pink, or White.
- The chosen color is carried through the main window, Companion shortcut, and Token Action HUD.
- Cut-in remains paired with its result popup and closes with that popup.
