# V3.0.53 — Boss Phase Transition / Skill Cut-in

## Boss Phase Transition

- Triggered by the existing GM phase switch control.
- Broadcast to everyone in the room.
- Displays the active phase Portrait, phase label, boss name, and previous-to-new form name for three seconds.
- Falls back to a cinematic Owlbear modal when the main extension window is closed.

## Skill Cut-in

- Open a Player sheet and edit a prepared ROLL Action.
- Enable `SKILL CUT-IN` for only the Actions that should use the effect.
- The Action card receives a `CUT-IN` badge.
- On roll, the Player Portrait and Action name appear for 1.2 seconds before the normal roll result.
- Study checks and monster Actions do not use Player Skill Cut-ins.
