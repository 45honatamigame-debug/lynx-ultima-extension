# Token Action HUD · Monster Resources · v2.163.7

- Monster HUD resource row is now **HP / MP / UP** only.
- Monster IP and FP controls were removed from the HUD.
- UP (Ultima Points) is always visible and supports the same `+10`, `-5`, or direct-value input commands as other resources.
- Monster Action cost prompt now exposes HP / MP / UP only; monster IP/FP costs are ignored by the HUD.
- Player HUD remains HP / MP / IP / FP.
