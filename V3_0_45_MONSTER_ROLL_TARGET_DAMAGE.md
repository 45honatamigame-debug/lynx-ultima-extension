# v3.0.45 — Monster Roll Target and Damage Controls

- Monster Roll cost window now includes a Player/Ally target list before resource cost and Roll Modifiers.
- Added random target count and random selection limited to Players and allied Monsters.
- Covered targets are blocked for enemy Melee Attacks and skipped by random Melee selection.
- The Monster Roll result now shows `APPLY DAMAGE` rows for every selected Player or Ally.
- Each result row supports editable base amount, hit count, VU/NORMAL/RES, HP/MP destination, and the shared DMG MOD.
- GM may apply each row separately or use `APPLY ALL`.
