# V3.0.6 · GM START GROUP CHECK

Core flow implemented from Fabula Ultima Group Checks:

1. GM chooses the common Attribute Check, Leader and Supporters.
2. Each Supporter performs the same Check at fixed DL 10.
3. Each successful Support Check adds +1 to the Leader.
4. The GM enters only the single highest applicable Bond strength among successful Supporters.
5. The Leader performs the normal Final Check with all bonuses.
6. Support Critical/Fumble are automatic success/failure but do not generate Opportunities.

Current Bond cards are free-text in this extension, so Bond strength is GM-confirmed rather than guessed from card text.
