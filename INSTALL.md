# Fabula v1.36 Install

Deploy this folder as a static site and keep the Owlbear Rodeo extension URL pointed at `/manifest.json`. Existing v1.35 character, Monster, Codex, Inventory, Sphere, Clock/Project, and UI preference data are reused automatically.

For offline-sheet persistence, open v1.36 in the room at least once while characters are present so their current Player Metadata can be mirrored into the Scene registry.
