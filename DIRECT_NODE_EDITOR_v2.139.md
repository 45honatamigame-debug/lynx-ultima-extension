# Direct Node Editor · v2.139

Base: stable `v2.138` (Node Token Templates retained).

Restored the Direct Node Editor behavior from `v2.131`:

- Removed the redundant Node dropdown from the GM Node Editor.
- Click a Node on the Node Board to edit that exact Node directly.
- The editor header shows the selected Node name.
- NAME, DETAIL, and UNLOCK RULE edit the currently clicked Node.
- A simple click (without dragging) focuses/selects the NAME field for immediate editing.
- Existing v2.138 Embedded Token / Node Token Template behavior is preserved.
- Ping remains removed; this build stays on the stable no-ping base.
