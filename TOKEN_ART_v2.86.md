# v2.86 Portrait Art / Token Art + Spawn & Link

- Player sheets now store Portrait Art and Token Art separately.
- Monster Templates and Monster Phases now store Portrait Art and Token Art separately.
- Existing selected-token-to-image behavior is renamed to Portrait From Selected Token.
- New Token Art can be selected from Owlbear Assets or copied from a selected Scene token.
- Players can SPAWN TOKEN + LINK STATS from their sheet.
- Monster Templates can spawn an Enemy/Ally token and create a Scene monster instance with stats linked immediately.
- Active Monster instances can SPAWN TOKEN + LINK STATS.
- LINK STATS to selected monster token is restored in both the header and portrait panel.
- Token spawning uses Owlbear Character image data, grid, scale, rotation, and places the token at the current viewport position.
