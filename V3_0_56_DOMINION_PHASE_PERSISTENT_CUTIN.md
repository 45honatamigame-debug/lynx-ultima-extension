# V3.0.56 — Dominion Phase and Persistent Cut-in

- Dominion Monster Sheet now offers `NEXT PHASE` while another monster phase remains.
- The shortcut updates active phase data and plays the shared Boss Phase Transition.
- Skill Cut-in no longer delays the roll result.
- The bottom-right Cut-in stays open until the matching Roll popup is closed or replaced locally.
- Continuous Cut-in animation was removed to reduce stutter.
