# v2.143 — High-visibility Travel Nodes

Travel Map Nodes now use substantially thicker, high-contrast borders so they remain readable over detailed map backgrounds.

- Base Node: 5px bright blue-gray border + dark outer separation ring.
- Reachable: vivid cyan border/ring/glow.
- Current: 6px white border + strong cyan outer ring/glow.
- Locked: vivid red border/ring/glow.
- GM Hidden: vivid amber dashed border/ring/glow.
- Selected: 7px yellow outline.
- Multi-selected: 6px cyan outline.

This patch changes presentation only. It does not change Node coordinates, hitboxes, connections, discovery, locking, travel, or permissions.
