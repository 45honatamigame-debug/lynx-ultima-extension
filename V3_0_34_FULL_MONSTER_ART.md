# v3.0.34 — Full Monster Artwork

- Monster artwork is rendered with `object-fit: contain` instead of cropping wherever it is exposed to players.
- Study Sheet portrait enlarged and kept fully visible.
- Companion Codex entries now include the monster image and show it uncropped.
- Main Codex expanded sheets now include a large full-art panel.
- Scene roster/current-turn/status/initiative surfaces preserve the complete monster image.
- Initiative Tracker monster avatars use a square contain frame rather than circular crop.
- Monster read-only sheets and Token Action HUD use uncropped portraits.
- Dominion/monster previews follow the same full-art rule for consistency.
