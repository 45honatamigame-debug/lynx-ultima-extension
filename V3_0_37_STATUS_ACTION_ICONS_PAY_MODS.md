# v3.0.37 — Status colors, Action type icons, PAY modifiers

- STATUS resources now use explicit color language: HP red, MP blue, IP purple, FP cyan/blue.
- Companion ACTIONS now show strongly differentiated colored icons/badges for Melee, Range, Two Weapon, Spell, and Other Action.
- PAY COST for roll actions now includes signed Accuracy Mod and Damage Mod inputs.
- PAY Accuracy Mod is added to the action accuracy modifier before rolling.
- PAY Damage Mod is added to the action damage bonus and survives Invoke recalculation.
