# DM TOKEN FRAME — v2.96

- GM-only TOKEN FRAME subtab in GM TOOLS.
- START TOKEN FRAME TOOL activates a persistent Pointer tool mode.
- Clicking an Owlbear CHARACTER image immediately attaches `token-frame.png` behind it.
- Frame uses the selected token bounds to match its footprint and follows position/scale/rotation through Owlbear attachment behavior.
- Existing frame for the same token is replaced, preventing duplicate stacking.
- Frame is a locked, hit-disabled PROP so it stays behind Character art and cannot steal clicks.
- REMOVE FRAME · SELECTED TOKEN provides an explicit undo path.
