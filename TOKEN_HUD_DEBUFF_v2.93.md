# TOKEN HUD DEBUFF VISIBILITY — v2.93

- Active monster/NPC Debuffs are always displayed on the linked-token HUD, even at Study 0.
- Study 0 HUD format: `NAME` + optional `· CRISIS`, followed by active Debuff chips on the next line.
- No active Debuff means no status line; `[NORMAL]` is never shown.
- Study privacy still hides HP / MP / DEF / M.DEF until their existing Study unlock tiers.
