# Token Action HUD Controls v2.163.2

Clean continuation of v2.163.1, which itself was built from v2.162.

- Added ARCANA tab for linked player sheets.
- Resource command fields accept signed deltas (+10 / -5) or absolute values (20).
- Added STATS button beside DEF/M.DEF.
- STATS overlay edits Base Attributes, Status Effects, Temp Modifiers, DEF MOD and M.DEF MOD without opening the Sheet.
- GM can edit linked Player/Monster actors; Players remain restricted to their own linked token.
